As promised during our call, I've done the research on open-source platforms that can serve as a foundation for your financial analysis platform for the Saudi market.



Good news — there are several strong options, and we don't need to build from scratch. Below is my recommended approach in two phases.



📌 PHASE 1 — MVP / Investor Demo ($2,000–3,500)



Goal: A working prototype with real data for 10–15 companies to show investors and test the concept.



Tech stack:
• Streamlit (open-source Python framework) — fastest way to build an interactive web app with financial charts. We can have a working demo in 1–2 weeks.
• Plotly — interactive charting library. Supports bar charts, line charts, time series — everything needed for revenue, profit margins, balance sheet visualization. We can add custom markers on charts (like CEO appointment dates overlaid on revenue timeline — exactly what you described during our call).
• PostgreSQL — database to store all the structured financial data from your Excel files.
• n8n — open-source automation tool to handle the pipeline: PDF upload → AI extraction → database → dashboard refresh.



What this MVP will include:
— Company profile page with ticker, name, sector
— Income Statement, Balance Sheet, Cash Flow charts (5-year history)
— Key financial ratios (calculated automatically from raw data)
— Filters by company, sector, period
— Basic AI chatbot to ask questions about company metrics



What it won't include (saved for Phase 2):
— Production-grade UI/UX
— Scalability for hundreds of concurrent users
— News feed integration from Saudi Exchange



📌 PHASE 2 — Scalable Product ($5,000–10,000)



Once the MVP is validated, we move the platform to a production-grade architecture:



Option A — Apache Superset or Metabase
These are open-source BI platforms used by companies like Airbnb and thousands of others. They offer:
— 40+ chart types out of the box
— Drag-and-drop dashboard builder
— Embeddable dashboards (can be placed inside your own branded website)
— Role-based access control (free vs. premium users in the future)
— Native connection to PostgreSQL (where your data lives)



Superset is more powerful and flexible. Metabase is simpler and faster to set up. I'll recommend the best fit once we see the MVP results.



Option B — Appsmith or ToolJet (low-code platforms)
If you want a UI closer to GuruFocus style with custom pages per company, these open-source low-code platforms let us build that faster than coding from scratch. They have ready-made widgets for tables, charts, and forms, and connect directly to databases and APIs.



For the AI chatbot, we would use LangChain + RAG (Retrieval-Augmented Generation) connected to your company database, so users can ask natural language questions like "What is the revenue per employee for Mahara?" and get accurate answers based solely on official financial data.



📌 BONUS OPTION — OpenBB Platform



OpenBB is an open-source project originally built as a free alternative to Bloomberg Terminal. It already has built-in logic for displaying Income Statements, Balance Sheets, and Cash Flows. If we can successfully replace their default data sources (US markets) with your Saudi data — this could accelerate development significantly. - Sanity checks (e.g., Assets = Liabilities + Equity, cash flow roll-forward)



- presentation/reclassification handling (TBD)
